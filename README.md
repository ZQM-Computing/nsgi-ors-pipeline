# NSGI-ORS Pipeline

Federal procurement pipeline enumeration and analysis for the NASA Space Grant Intergovernmental/Institutional Relations (NSGI) Office of Research Support (ORS).

## Overview

This repository contains authoritative documentation and analysis for the NSGI-ORS federal procurement pipeline:

- **Master Enumeration**: Complete listing of active procurement opportunities
- **Verification Pass**: Validated and cross-referenced opportunities
- **Easy Projects**: Simplified project opportunities for quick wins
- **CDC Draft**: Contract Data Requirements List (CDRL) draft documentation
- **Stale Listing Audit**: Review of outdated or expired listings

## Usage

All documentation is in Markdown format. Open the files in the `authoritative/` directory to review:

1. Start with `NSGI_ORS_Master_Enumeration` for full context
2. Review `Verification_Pass` for validated opportunities
3. Check `Easy_Projects` for quick-start items
4. See `CDC_Draft` for contract package details
